# AutoCAD-MCP 接口文档

本文档描述 MCP Server 暴露的全部 82 个接口（MCP 工具）的参数与调用示例。

## 总览

| 分类 | 数量 | 工具 |
| --- | --- | --- |
| 绘图 | 9 | line / circle / arc / rectangle / polyline / ellipse / spline / polygon / point |
| 文字与标注 | 4 | draw_text / dimension / leader / hatch |
| 图层与文件 | 3 | set_layer / layer_manage / dwg_op |
| 编辑 | 18 | transform / delete / offset / trim / extend / fillet / chamfer / break / stretch / align / change_properties / erase_by_filter / undo / explode / join_entity / array / array_rect / array_polar |
| 块与组 | 5 | insert_block / block_query / block_attr / block_replace / group_op |
| 查询 | 19 | get_drawing_summary / get_drawing_fingerprint / query_entities / get_entity / entity_info / entity_count / find_text / get_bounds / sysvar / query_relations / trace_boundary / verify_result / compare_drawings / list_styles / get_selection / get_dwg_info / read_commandline / layer_query / list_all |
| 几何计算 | 4 | geo_basic / geo_query / calc_area / divide_curve |
| 空间感知 | 6 | connected / inside / aligned / detect_clash / find_vacant / detect_islands |
| 文件与数据 | 11 | list_files / read_file / write_file / delete_file / append_file / replace_in_file / save_library / list_outputs / export_csv / create_table / param_set |
| 辅助 | 3 | ping / cad_bridge_health / get_drawing_info |

## 通用约定

- **点**：`[x, y]` 或 `[x, y, z]` 数组（z 缺省为 0）。
- **handle**：图元句柄字符串（由 query 类工具返回，如 `"1A3"`）。
- **选择集**（handles / entities / selection 三选一，缺省用当前选择集）：
  - `handles`: handle 字符串数组，如 `["1A3","1A4"]`（必须是数组，不能用逗号拼接的单个字符串 `"1A3,1A4"`）；
  - `entities` 或 `selection`: 选择描述对象，如 `{"mode": "all", "layer": "0"}`；
  - 选择描述支持字段：`mode`（all / handles / last / window / crossing / filter）、`type`、`layer`、`color`、`block`。
- **space**：`current`（默认）/ `model` / `paper` / `all`。
- **颜色 color**：`"red"` 等颜色名、ACI 索引 `"1"`、或 `"255,0,0"`（R,G,B）。
- **角度**：单位均为度（C# 端自动转弧度）。
- **绘图工具单一模式**：line / circle / arc / rectangle / ellipse 均为单一模式，直接给出对应参数即可（line：start+end；circle：center+radius；arc：center+radius+start_angle+end_angle；rectangle：p1+p2；ellipse：center+major_radius+minor_radius）。
- **多模式工具**：hatch / dimension 等仍支持多种互斥模式，参数表“必填”列的 `条件A` / `条件B` 表示仅在对应模式必填；请按“模式”表给出的参数组合调用，不要混用不同模式的参数。模式判定只看参数是否提供，与坐标值无关（`[0,0]` 是合法坐标）。
- **响应格式**：统一 `{"success": true, ...payload}`；失败 `{"success": false, "error": "..."}`。
- **执行前提**：CAD 类工具需 AutoCAD 已 NETLOAD 插件并执行 `MCPBRIDGESTART`；文件类工具在 Python 本地执行，输出目录默认 `~/Documents/AutoCAD-MCP`（环境变量 `AUTOCAD_MCP_OUTPUT_DIR` 可覆盖）。

# 一、绘图（9）

### line — 绘制直线

单一模式（两点）。

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| start | [x,y] | ✓ | — | 起点（`[0,0]` 合法） |
| end | [x,y] | ✓ | — | 终点 |
| layer / color | string | | "" | 图层 / 颜色 |

**示例**：

```json
{"start": [0, 0], "end": [100, 50]}
```

# 二、文字与标注（4）

### draw_text — 绘制文字

**单模式，无互斥参数**（kind 仅切换单行/多行文字，其余参数含义不变）。

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| position | [x,y] | ✓ | — | 插入点 |
| text | string | ✓ | — | 文字内容 |
| height | number | | 2.5 | 字高 |
| rotation | number | | 0 | 旋转角（度） |
| kind | string | | "text" | text 单行文字 / mtext 多行文字 |
| align | string | | "left" | left / center / right / middle / top / bottom / topleft / topcenter / topright / middleleft / middleright / bottomleft / bottomright |
| width | number | 条件 | 0 | mtext 宽度（仅 kind="mtext" 且 >0 时生效） |
| width_factor | number | | 1 | 宽度因子 |
| style | string | | "" | 文字样式名 |
| layer / color | string | | "" | 图层 / 颜色 |

**示例**：

```json
{"position": [10, 20], "text": "标题", "height": 5, "align": "center"}
{"position": [10, 20], "text": "多行说明文字", "kind": "mtext", "width": 60, "height": 3.5}
```

### dimension — 创建尺寸标注

**模式（由 type 决定，参数组合互斥）**：

| type | 必填参数组合 | 可选参数 | 禁止同时提供 |
| --- | --- | --- | --- |
| linear | `p1` + `p2` + `p3` | rotation | start1/end1/start2/end2、vertex、center、chord_point |
| aligned | `p1` + `p2` + `p3` | — | 同上 |
| angular 四线式 | `start1` + `end1` + `start2` + `end2`（四点齐全） | arc_point | vertex、p1/p2、center、chord_point |
| angular 三点式 | `vertex` + `p1` + `p2` | arc_point | start1/end1/start2/end2、center、chord_point |
| radius | `center` + `chord_point` | leader_length | p1/p2/p3、start1~end2、vertex |
| diameter | `center` + `chord_point` | leader_length | 同上 |

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| type | string | ✓ | — | linear / aligned / angular / radius / diameter |
| p1 | [x,y] | 条件 | — | linear/aligned：第一条延伸线原点；angular 三点式：边 1 端点 |
| p2 | [x,y] | 条件 | — | linear/aligned：第二条延伸线原点；angular 三点式：边 2 端点 |
| p3 | [x,y] | 条件 | — | linear/aligned：尺寸线位置点 |
| rotation | number | | 0 | linear 标注方向角（度） |
| center | [x,y] | 条件 | — | radius/diameter：圆心 |
| chord_point | [x,y] | 条件 | — | radius/diameter：圆上点（决定半径） |
| leader_length | number | | 0 | radius/diameter 引线长（≤0 自动取半径 30%） |
| start1 / end1 | [x,y] | 条件 | — | angular 四线式：边 1 起点 / 终点 |
| start2 / end2 | [x,y] | 条件 | — | angular 四线式：边 2 起点 / 终点 |
| vertex | [x,y] | 条件 | — | angular 三点式：角顶点 |
| arc_point | [x,y] | | — | angular 弧标注位置（缺省自动沿角平分线偏移） |
| layer / color | string | | "" | 图层 / 颜色 |

**调用规则**：
- `type` 必填；angular 判定顺序：给出 `start1` 则按四线式处理（此时 `end1`/`start2`/`end2` 缺失会报“缺少参数”），否则按三点式取 `vertex`+`p1`+`p2`。
- 不同 type 下 `p1/p2` 含义不同（linear/aligned 为延伸线原点，angular 三点式为两边端点）。

**示例**：

```json
{"type": "linear", "p1": [0, 0], "p2": [100, 0], "p3": [50, -15]}
{"type": "aligned", "p1": [0, 0], "p2": [80, 60], "p3": [40, 60]}
{"type": "angular", "start1": [0, 0], "end1": [50, 0], "start2": [0, 0], "end2": [35, 35], "arc_point": [20, 10]}
{"type": "angular", "vertex": [0, 0], "p1": [50, 0], "p2": [35, 35]}
{"type": "radius", "center": [0, 0], "chord_point": [30, 0]}
{"type": "diameter", "center": [0, 0], "chord_point": [30, 0], "leader_length": 12}
```

**单模式，无互斥参数**。

| --- | --- | --- | --- | --- |
| points | [[x,y],...] | ✓ | — | 引线顶点，至少 2 点（首点靠文字侧） |
| text | string | | "" | 引线文字 |
| height | number | | 0 | 文字高度（>0 生效） |
| layer / color | string | | "" | 图层 / 颜色 |

### hatch — 创建图案填充

**模式（互斥，二选一）**：

| 模式 | 必填参数组合 | 判定条件 |
| --- | --- | --- |
| A 图元边界 | `handles`（非空数组） | handles 非空时优先，忽略 point |
| B 内部点 | `point` | handles 为空或未提供时使用 |

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| handles | [string] | 条件A | — | 闭合边界图元 handle 列表（非空） |
| point | [x,y] | 条件B | — | 边界内部点，自动追踪边界 |
| pattern | string | | "SOLID" | 图案名（SOLID / ANSI31 / HONEY 等） |
| scale | number | | 1 | 图案比例 |
| angle | number | | 0 | 图案角度（度） |
| associative | bool | | true | 关联填充 |
| layer / color | string | | "" | 图层 / 颜色 |

**调用规则**：`handles` 与 `point` 至少提供一个；两者都未提供时返回错误 `"hatch 需要边界 handles 或内部 point"`。`handles` 非空时优先于 `point`；point 模式自动追踪出的边界曲线会一并写入当前空间。

**示例**：

```json
{"point": [25, 25], "pattern": "ANSI31", "scale": 0.5}
{"handles": ["1A3", "1A4"], "pattern": "SOLID"}
```

**功能**：图层不存在时自动创建；on/freeze/lock/plottable 为 null 表示不改动。

| 参数 | 类型 | 必填 | 默认 | 说明 |

| linetype | string | | "" | 线型名 |


### dwg_op — DWG 文件管理

**功能**：op 支持 new / open / save / saveas / close / export_pdf / export_dxf / audit / info。

| --- | --- | --- | --- | --- |

### detect_clash — 检测图元碰撞/相交

**功能**：set_a / set_b 为两组图元；缺省用同一选择集两两检测。共享端点的接触不算冲突。

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| tolerance | number | | 0.0001 | 容差 |
| set_a / set_b | [string]\|dict | | null | 两组图元（handle 列表或选择描述） |
| handles | [string] | | null | 图元 handle 列表（单组两两检测） |
| entities / selection | dict | | null | 选择描述对象 |

**示例**：

```json
{"set_a": ["1A3", "1A4"], "set_b": ["1A5", "1A6"]}
{"handles": ["1A3", "1A4", "1A5"]}
```

### find_vacant — 查找空位

**功能**：在区域中查找可容纳 width×height 矩形的空位。

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |

| height | number | ✓ | — | 所需高度 |
| p1 / p2 | [x,y] | | null | 搜索区域对角点（缺省当前空间范围） |
